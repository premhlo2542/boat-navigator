# Boat Navigator

PWA นำทางเรือแบบ mobile-first ใช้ GPS ของอุปกรณ์ เก็บข้อมูลในเครื่อง (IndexedDB) ใช้งานได้บางส่วนแบบออฟไลน์
**Safety First, Clarity Second, Beauty Third.** — เครื่องมือช่วยประกอบ ไม่ใช่เครื่องนำทางหลัก และไม่ทดแทนแผนที่เดินเรือทางการ

## Architecture (สรุป)

ไม่มี build step: เครื่องที่พัฒนาไม่มี Node.js จึงเลือก **vanilla JavaScript (ES modules) + Leaflet 1.9.4 + leaflet-rotate 0.2.8 (vendored)** แทน React/TypeScript/Tailwind
(ข้อจำกัดนี้ไม่ลดความสามารถหลัก; ถ้าต้องการย้ายไป React + TS ทีหลัง โมดูลแกนกลางที่ไม่แตะ DOM — `util.js`, `gps.js`, `nav.js`, `trip.js`, `db.js`, `gpx.js` — ย้ายได้ตรง ๆ)

| ไฟล์ | หน้าที่ |
|---|---|
| `js/gps.js` | `watchPosition` + watchdog (ok → stale 10 วิ → lost 30 วิ), เข็มทิศอุปกรณ์ (ไม่บังคับ) |
| `js/nav.js` | นำทางหลายจุด, ระยะ/ทิศ/ETA, ออกนอกเส้นทาง (cross-track), Anchor Watch |
| `js/trip.js` | บันทึกทริป เริ่ม/พัก/จบ, เขียน IndexedDB ทุก 10 จุด, กู้คืนหลังแอปปิด |
| `js/db.js` | IndexedDB: `places`, `routes`, `trips` |
| `js/map.js` | Leaflet wrapper (ชั้นข้อมูลแยกจากสถานะแอป เปลี่ยนผู้ให้บริการแผนที่ได้ที่ `applyTiles`) |
| `js/views.js` | หน้า Routes / Places / Trips / Settings |
| `js/main.js` | bootstrap, HUD, ค้นหา, alerts, lifecycle |
| `sw.js` | precache shell + แคชเฉพาะ tile ที่เคยดู (สูงสุด 1,200 tile) |
| `css/app.css` | Design tokens (dark / light / high-contrast), components |

## รันโปรเจกต์

ต้อง serve ผ่าน HTTP(S) (ES modules และ service worker ใช้ `file://` ไม่ได้):

```powershell
python -m http.server 8080          # หรือ
powershell -File tools/serve.ps1    # ถ้าไม่มี Python
```
เปิด `http://localhost:8080`

**ทดสอบบนมือถือ:** Geolocation ต้องใช้ **HTTPS** (ยกเว้น localhost) — deploy ขึ้น static hosting ที่เป็น HTTPS (GitHub Pages, Netlify, Cloudflare Pages) หรือใช้ tunnel (`cloudflared tunnel --url http://localhost:8080`) แล้วเปิดบนมือถือ
iOS: Safari → Share → Add to Home Screen. Android: Chrome → Install app.

## API Keys / การตั้งค่าภายนอก

**ไม่ต้องมี API key** และไม่มี secret ในโค้ด แต่ผู้ให้บริการที่ใช้มีเงื่อนไข:

| บริการ | ใช้ทำอะไร | หมายเหตุ |
|---|---|---|
| OpenStreetMap tiles | แผนที่พื้นฐาน | [Tile Usage Policy](https://operations.osmfoundation.org/policies/tiles/) — เหมาะกับการใช้งานเบา/ส่วนตัว ห้าม bulk download ถ้าใช้งานเชิงพาณิชย์หรือมีผู้ใช้จำนวนมาก ให้ใช้ tile provider ของตัวเอง/เชิงพาณิชย์ (Settings → แผนที่ → กำหนดเอง) |
| OpenSeaMap seamarks | ทุ่น/ไฟ/เครื่องหมายเดินเรือ | ข้อมูลอาสาสมัคร **ไม่ใช่ข้อมูลเดินเรือทางการ** |
| Nominatim | ค้นหาสถานที่ | [Usage Policy](https://operations.osmfoundation.org/policies/nominatim/): ค้นหาเมื่อกด Enter เท่านั้น (ไม่ autocomplete) ≤ 1 คำขอ/วินาที ไม่เหมาะกับปริมาณสูง |

Custom tile URL ต้องตอบ CORS (`Access-Control-Allow-Origin`) เพื่อให้ service worker แคชได้ ถ้าไม่มีก็ยังแสดงผลได้แต่ไม่แคช

## ฟีเจอร์: ทำงานจริง / จำลอง / ข้อจำกัด

**ทำงานจริง (ทดสอบอัตโนมัติแล้วบางส่วน ดู “สถานะการทดสอบ”)**
- แผนที่เต็มจอ ซูม/เลื่อน, ตำแหน่งเรือจาก GPS, วงความแม่นยำ, Recenter + โหมดติดตามเปิด/ปิด
- **เข็มทิศเปิดอัตโนมัติเสมอ** (Android ทันที / iOS หลังแตะหน้าจอครั้งแรกแล้วกดอนุญาต) หัวเรือ = ทิศจาก GPS เมื่อเรือแล่น (เกิน ~1.5 นอต) ไม่งั้นใช้เข็มทิศมือถือ ไม่มีเซนเซอร์ก็แสดง "ไม่มีข้อมูล"
- **แผนที่หมุนตามหัวเรือ:** ลูกศรเรือชี้ขึ้นด้านบนเสมอ แผนที่หมุนแทน (ปุ่มเข็มทิศสลับเป็นเหนือขึ้นบนได้) แตะที่ลูกศรเรือหรือปุ่มเป้าเพื่อซูมเข้าและล็อกตามเรือ เหมือน Google Maps
- **HUD ภาษาง่าย:** ขณะนำทางแสดง ความเร็ว / เหลืออีก (เวลา) / ถึงเมื่อ (เวลาถึง) / ระยะเหลือ; ตอนไม่นำทางแสดง ความเร็ว / ทิศที่ไป / เวลาเดินทาง / ไปแล้ว แตะเพื่อดูเพิ่ม (ตำแหน่ง, ความแม่นยำ GPS, หัวเรือ, เบี่ยงจากเส้นทาง) เวลาเหลือและเวลาถึงคำนวณจากความเร็วเฉลี่ยจริง ถ้าเรือหยุดหรือช้ามากจะใช้ความเร็ววางแผนและติดป้าย "ประมาณ"
- ค้นหา (Nominatim) + พิกัดทศนิยม + สถานที่ที่บันทึก; แตะแผนที่เพื่อเลือกจุดหมาย
- นำทางหลายจุด เลื่อนไปจุดถัดไปอัตโนมัติ กู้คืนหลังรีเฟรช
- Routes: เพิ่ม/ลบ/เรียง (ปุ่มขึ้น-ลง) จุด, ระยะรวม, เวลาประมาณที่ความเร็ววางแผน, บันทึก/โหลด/ลบ
- Places: บันทึกตำแหน่งปัจจุบัน/พิกัดมือ, หมวดหมู่, หมายเหตุ, แก้ไข, ลบ (ยืนยันก่อน)
- Trips: เริ่ม/พัก/จบ, เก็บลง IndexedDB ต่อเนื่อง, กู้คืนหลังแอปปิด, ดูบนแผนที่, ส่งออก **GPX 1.1**
- Alerts: GPS ขาด/ข้อมูลเก่า/แม่นยำต่ำ/ไม่ได้รับอนุญาต, ออกนอกเส้นทาง, ถึงจุดหมาย, ออฟไลน์, แผนที่โหลดไม่ได้
- เตือนเรือลอย / Anchor Watch (รัศมี 10–1000 ม., หักความคลาดเคลื่อน GPS, เตือนเสียง/สั่น, เตือนเมื่อ GPS ขาด)
- PWA: manifest, service worker, ติดตั้งได้, เปิดแอปและดูข้อมูลที่บันทึกไว้ออฟไลน์
- Dark / Light / High-contrast, safe-area, Wake Lock (ถ้าเบราว์เซอร์รองรับ)

**ไม่ได้ทำ / ข้อจำกัดที่ต้องรู้**
- **เส้นทางเป็นเส้นตรงเสมอ** และถูกติดป้าย “ยังไม่ผ่านการตรวจสอบความปลอดภัยทางทะเล” — ไม่มีข้อมูลความลึก สิ่งกีดขวาง เขตหวงห้าม หรือ routing ทางน้ำ (ต้องมีแหล่งข้อมูลเช่น ENC/S-57 ที่มีสิทธิ์ใช้งาน)
- **ไม่ตรวจจับอันตรายหรือป้องกันการชน**
- ออฟไลน์: แคชเฉพาะ tile ที่เคยดู **ไม่มีระบบดาวน์โหลดแผนที่ทั้งพื้นที่** (ผิดนโยบาย OSM; ต้องมี tile source ที่อนุญาต)
- แผนที่ที่หมุนจะหมุนป้ายชื่อถนนตามไปด้วย (ข้อจำกัดของ raster tiles)
- Heading จากเข็มทิศ = ทิศของ**โทรศัพท์** ไม่ใช่หัวเรือ ถ้าไม่ได้ยึดโทรศัพท์ขนานกับเรือจะผิด (ตอนเรือแล่นแอปใช้ทิศจาก GPS ซึ่งแม่นกว่า) และคลาดเคลื่อนได้เมื่ออยู่ใกล้โลหะหรือเครื่องยนต์
- เว็บแอปบน iOS/Android **ไม่รับประกัน GPS เบื้องหลัง**: หน้าจอล็อก/สลับแอปอาจหยุดบันทึกและ Anchor Watch ให้เปิดแอปค้างหน้าจอไว้ (Wake Lock ช่วยได้ แต่ iOS บางรุ่นไม่รองรับใน PWA)
- SOG/COG มาจากค่าที่ OS ให้; ถ้าอุปกรณ์ไม่ให้ `speed` จะแสดง “ไม่มีข้อมูล” (ไม่คำนวณแทน)
- ไม่มีการซิงก์ข้ามอุปกรณ์/บัญชี; ล้างข้อมูลเบราว์เซอร์ = ข้อมูลหาย (แอปขอ persistent storage แต่ไม่รับประกัน) ควรส่งออก GPX เป็นระยะ
- ยังไม่มีส่งออก/นำเข้า Waypoints และ Routes (ส่งออกเฉพาะ Trip เป็น GPX)
- ยังไม่มี Geofence นอกจาก Anchor Watch

## สถานะการทดสอบ

ทดสอบแล้ว (headless Edge/Chromium, GPS จำลอง): `tools/smoke.html` — การคำนวณระยะ/ทิศ/cross-track, รูปแบบพิกัด, GPX well-formed, boot ของแอป, HUD ไม่แสดงค่าปลอมเมื่อไม่มี GPS, บันทึกทริป + IndexedDB, ออกนอกเส้นทาง, ถึงจุดหมาย, GPS ขาด, Anchor alarm, การเรนเดอร์ทุกแท็บ, service worker แคช shell
รันซ้ำ: เปิด server แล้วไปที่ `/tools/smoke.html` (ผลขึ้นด้านบนหน้า) หรือ `powershell -File tools/cdp-eval.ps1 -Url http://127.0.0.1:8765/tools/smoke.html -Expr "document.getElementById('out').textContent"`

**ยังไม่ได้ทดสอบ:** อุปกรณ์ iOS/Android จริง, GPS จริงกลางแจ้ง, เข็มทิศ, Wake Lock, การติดตั้ง PWA บนมือถือ, offline จริง, Safari
